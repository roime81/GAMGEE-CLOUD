Scale

Add compute

Add worker machines to the same GAMGEE cloud. Applications remain in the same workspace model.

1. Get the node join token on the control-plane machine

Run this on the machine where GAMGEE Core Cloud is installed. Treat the token like a root password and share it only over a trusted private channel.

sudo cat /var/lib/rancher/k3s/server/node-token

2. Join the worker

On the worker, check out the same GAMGEE release and run the join script. It prompts for the token without echoing it or putting it in shell history.

sudo bash scripts/join-compute-node.sh https://CONTROL-PLANE-DNS-OR-IP:6443

Pin GAMGEE_K3S_VERSION to the exact version shown by k3s --version on the control-plane node. Keep TCP 6443 and the K3s node traffic ports reachable only on your trusted private network.
